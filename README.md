# Learning Python

My Python learning log as I work toward applied AI engineering.

I'm working through Harvard's [CS50P](https://cs50.harvard.edu/python/) and building small original scripts alongside each lecture. Problem set solutions are submitted through CS50 and aren't posted here, in line with the course's academic honesty policy. Everything in this repo is my own work.

## What's here

### Week 1: Functions, variables, and strings

| Script | What it does |
|---|---|
| `bill_splitter.py` | Calculates the tip and each person's share of a bill |
| `script_timer.py` | Estimates read-aloud time for a voiceover script |
| `title_cleaner.py` | Cleans a messy video title and makes a filename-safe version |
| `rpm_calculator.py` | Estimates earnings from views and RPM |
| `source_header.py` | Generates source headers for my Case File Assistant project |
| `unit_converter.py` | Converts total seconds to hours, minutes, and seconds |

## How to run

Requires Python 3.

```
git clone https://github.com/Michael-Aeye/learning-python.git
cd learning-python
python week-1/bill_splitter.py
```
