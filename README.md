My Python learning log as I work toward applied AI engineering.

I'm working through Harvard's [CS50P](https://cs50.harvard.edu/python/) and building small original scripts alongside each lecture. 
Problem set solutions are submitted through CS50 and aren't posted here, in line with the course's academic honesty policy.
Everything in this repo is my own work.

## What's here

### Week 1: Functions, variables, and strings

| Script | What it does |
|---|---|
| `bill_splitter.py` | Calculates the tip and each person's share of a bill |
